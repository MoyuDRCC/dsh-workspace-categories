# 工作区分类（dsh-workspace-categories）

给 Harness 侧栏的工作区列表加一层自定义分类：把十几个平铺的工作区收进
"前端 / 服务端 / 临时项目"这样的桶里，需要时再展开。

## 用法

- **切换到分类视图**：视图选项菜单（列表标题栏的 ⋯）→ 分组方式 → 按分类。
  原有的按工作区 / 按工作区树 / 单列表保持原样，可随时切回。
- **定位当前会话**：点击工作区标题栏的准星按钮，列表会展开当前会话所属位置并滚动到会话行；分类折叠或进入其他分类时也会自动切换。若筛选条件隐藏了当前会话，会切换为显示全部会话。
- **新建分类**：左侧面板头部的 ＋ 菜单 → 新建分类（进入式根级也有“＋ 新建分类”一行）。
- **归类**：工作区行的 ⋯ 菜单 → 移动到分类；或直接把工作区行拖到分类头上。
- **排序**：拖动分类头到另一个分类的前/后，即可调整分类顺序（未分类固定在末尾）。
- **树形**：分类头就地展开成员，可折叠；未分类的工作区归入"未分类"桶，排在最后。
  每个分类有固定的彩色标记，分类下的工作区与分类头的展开箭头对齐。
- **进入式**：根级只列分类，点进去看该分类的工作区，顶部返回行回到根级；
  点开某分类里的会话时，视图会自动跟随到该会话所属的分类。
- 两种呈现方式在视图选项菜单的"分类展示"里切换，选择与折叠状态记在浏览器本地。

## 数据在哪

- 分类与归属：`$DSH_HOME/plugin-data/dsh-workspace-categories/state.json`，
  由 Host 端点 `/api/dsh-workspace-categories/state` 读写。
- 内置的 `workspace` 域（`$DSH_HOME/storages/workspace.json`）不会被改写；
  工作区被删除后，其归属会在下次读取时自动清理。

## 为什么内置的 ui-workspace 被停用

内置的 `@deepseek-ai/dsh-client-ui-workspace` 同时提供侧栏浏览区占用和共享服务
`ctx.uiWorkspace`（侧栏、会话页、目录选择器都依赖它），所以无法只在旁边"叠加"
一个视图。本插件在 `client.js` 里内置该包的副本（MIT，见
`THIRD_PARTY_NOTICES.md`），保留它全部服务、槽位与子洞，只在列表渲染处加入分类层。

## 恢复官方默认

在插件管理里停用本 bundle（`dsh-workspace-categories`）即可：本包自带 patch 层里的
`disabled: true` 一并失效，内置 `ui-workspace` 回到官方状态；刷新页面后生效。
只停用插件行不够——那会留下一个没有 `uiWorkspace` 服务的侧栏，浏览区无法挂载。
分类数据文件保留在 `plugin-data` 下，重新启用后继续使用。
